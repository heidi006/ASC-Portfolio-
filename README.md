## 1. Bluetooth 4WD Autonomous Vehicle Firmware
- Focus: Embedded Systems, C++, Microcontrollers, Safety Logic
- Description: Developed custom C++ firmware for a four-wheel vehicle with real-time sensor processing and motor state control.
- Key Technical Features:
  * Motor State Logic: Designed change-detection control logic for dynamic motion commands.
  * Sensor Integration: Interfaced MPU6050 IMU over I2C for attitude and balance monitoring.
  * System Safety: Implemented a automatic signal-loss timeout safety stop to prevent runaway conditions.
  * Telemetry: Configured real-time battery voltage monitoring and Bluetooth telemetry feedback.
- Tools & Tech: C++, Arduino IDE, MPU6050, I2C, Bluetooth Protocols.
